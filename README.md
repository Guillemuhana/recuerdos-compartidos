# Recuerdos Compartidos

App web moderna en React + Vite para **Recuerdos Compartidos**, memoriales multimedia con QR.

## Ejecutar en Visual Studio Code

```bash
npm install
npm run dev
```

## Publicar en GitHub

```bash
git init
git add .
git commit -m "Recuerdos Compartidos app inicial"
git branch -M main
git remote add origin https://github.com/Guillemuhana/recuerdos-compartidos.git
git push -u origin main
```

## Publicar en Vercel

1. Entrar a vercel.com.
2. Importar el repositorio de GitHub.
3. Framework: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.

## Editar datos

Los textos están en `src/main.jsx` y el estilo en `src/styles.css`.
Las imágenes están en `public/assets`.
